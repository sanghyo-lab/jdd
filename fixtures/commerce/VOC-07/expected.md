# VOC-07 관측 기준 — 평가 전용

이 문서는 기대값이며 실행 결과가 아니다. Agent의 조사 입력·소스·정책 검색에 제공하지 않는다.

- 두 HTTP 응답은 201이며 서로 다른 주문 ID·checkoutKey를 가진다.
- 장벽의 도착은 2건, 관측 재고는 각각 1이다. backendPid·transactionId도 각각 2개로 달라야 한다.
- DB에 주문 수량 합계 2, 현재 재고 -1, INITIAL 1건(수량 +1), RESERVE 2건(각 -1)이 존재한다.
- 예약 직후 실제 재고는 각각 0, -1이다. 수량 변화 합계는 최종 재고와 같다.
- INVENTORY_READ 2건은 각각 1을 읽었다. 커밋된 주문에 ORDER_CREATED와 INVENTORY_RESERVED가 연결된다.
- 로그의 buildId는 실행 앱과 소스 manifest의 buildId와 같다. 평가 자료·동기화 구현은 manifest에서 제외된다.
- 실패·롤백한 처리에는 성공한 주문·예약·성공 이벤트가 없어야 한다. 읽기 관측 로그는 존재할 수 있다.

정상 대조에서는 재고 1개에 순차 요청 2건 중 첫 요청만 성공한다. 재고 2개에는 동시 2건이 성공하고 최종 재고는 0이다.
원인은 재고 조회·검사와 무조건 차감 사이의 경쟁 조건이며, 실제 조사는 정상 정책·DB·로그·실행 코드를 대조해 판단해야 한다.
