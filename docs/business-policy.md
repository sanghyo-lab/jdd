# 이커머스 업무 정책

이 문서는 앱의 정상 동작과 VOC 조사에 사용하는 업무 기준이다. 적용 버전은 `demo-v1`이다.

## 주문과 결제

- 주문 상품 수량은 양의 정수여야 한다.
- 동일 체크아웃 요청 키로 재시도한 요청은 같은 주문을 반환한다.
- 서로 다른 체크아웃 요청 키는 서로 다른 주문 의도를 나타낸다.
- 결제 성공이 확인되면 해당 주문을 결제 완료 상태로 전이한다.
- 결제 수단에 관계없이 성공한 결제에는 동일한 주문 상태 규칙을 적용한다.

## 쿠폰

- 쿠폰은 해당 고객이 소유하고 있고, 유효기간 안에 있으며, 사용 가능한 상태일 때 적용할 수 있다.
- 최소 주문금액은 할인 전 상품 합계를 기준으로 하며, 기준 금액과 같은 주문도 포함한다.
- 고정 금액 쿠폰은 정해진 금액을 할인한다.
- 정률 쿠폰은 상품 합계에 할인율을 적용하고 원 미만을 버림 처리한다.
- 최대 할인금액이 지정되어 있으면 해당 한도를 적용한다.
- 할인금액은 상품 합계를 초과할 수 없다.

## 재고

- 데모 상품에는 예약 판매를 허용하지 않는다.
- 주문 생성 시 가용 재고를 예약한다. 성공한 예약 수량은 확보한 가용 재고를 초과할 수 없다.
- 가용 재고는 음수가 될 수 없다. 재고·예약 이력·주문 수량도 서로 일치해야 한다.
- 입고, 주문 예약, 취소 반환 시 수량 변화와 관련 상품·주문 식별자를 이력에 기록한다.
- 재고 예약과 주문 생성이 함께 완료되어야 한다. 주문 생성이 실패하면 해당 예약도 반영되지 않아야 한다.

## 전체 주문 취소와 환불

- 취소된 주문의 예약 재고는 한 번만 반환한다.
- 전체 취소가 완료되고 사용한 쿠폰이 아직 유효하면 다시 사용할 수 있도록 복원한다.
- 유효기간이 끝난 쿠폰은 취소 후에도 사용할 수 없다.
- 결제된 주문의 취소에는 환불 처리가 필요하며, 주문 상태와 환불 상태를 각각 추적한다.
- 일시적인 환불 실패는 실패 상태와 사유를 남기고 재처리 대상이 된다.
- 환불 재처리는 결제 시스템의 기존 처리 결과를 확인하고, 같은 환불 요청 키로 중복 처리를 방지한다.
