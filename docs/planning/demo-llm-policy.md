# AI 인증·프로모션·비용 사용 규칙

2026-09-21 최신 사용자 지시: **로컬 개발·반복 실행·영상 데모는 Codex OAuth, 배포·배포 미리보기는 OpenAI API key, 자동 테스트는 networkless mock**이다.
이 정책은 이전의 “로컬 데모에 API 키” 방침을 대체한다. 실행 계약/명령/기능 차이는 [LLM 실행 설명](../llm-runtime.md)을 따른다.

## 인증과 실행 분리

- APP_RUNTIME과 LLM_PROVIDER를 명시한다. local/codex_oauth, deployed/openai_api, test/mock 외에는 시작 오류다.
- 로컬 production 빌드도 OAuth다. 키의 우연한 존재, NODE_ENV, localhost 여부로 provider를 고르지 않는다.
- 로컬은 프로젝트 전용 저장소 밖 auth.json을 매 요청 읽고 초기 로그인/재로그인은 공식 CLI만 사용한다. refresh를 임의로 구현하지 않는다.
- OAuth 오류·만료·사용량 제한·모델 권한·timeout 때 API key로 fallback하지 않는다. 배포는 OAuth 파일을 읽지 않는다.
- 앱 요청마다 Codex CLI/코딩 에이전트를 실행하지 않고 로컬 Agent가 Codex backend Responses를 직접 호출한다.
- Codex OAuth의 워크스페이스 조건/지원 모델/한도/무제한 혜택을 단정하지 않는다. 실제 계정 접근 검증을 별도로 기록한다.
- 자동 test/check/publish/up은 실제 모델이나 ngrok 터널을 자동 활성화하지 않는다. live smoke는 별도 명령이다.

## 프로모션과 배포 예산

사용자가 전달한 적용 기록은 **$50.00, 2026-09-21 적용**이다. 현재 잔액·만료일·대상 조직/프로젝트는 별도 확인 사항이다.
이 API 크레딧은 배포 환경에만 사용한다. 로컬 연결 검증·개발·데모 영상에 프로모션 키를 사용하지 않는다.
프로모션 코드와 API 키는 다르며, 키는 배포 Agent의 OPENAI_API_KEY secret으로만 주입한다. API 키 파일 경로는 사용하지 않는다.
$50 제공을 기존 예산의 자동 증액으로 해석하지 않는다. 누적 $30 초과가 예상되면 새 유료 호출을 중단하고 별도 범위/예산을 정한다.

기존 영속 API 장부와 원자적 비용 예약을 유지한다. 확정+미확정+진행 중 예약+새 호출 최대 비용을 검사하며,
재시작·재조사·다른 범위 이름으로 한도를 초기화하지 않는다. 계정/여러 배포의 전체 사용액을 한 DB 장부가 대신하지 않는다.
모델별 입력·출력·캐시·reasoning을 실제 사용량으로 정산하고 reasoning 중복 합산/미관측 0 처리를 하지 않는다.
OAuth는 별도 관측 장부에 기록하며 API USD 가격을 적용하지 않는다. ngrok 요금도 별도 항목이다.

배포 profile은 범위·모델·최대 호출/비용·만료·검토된 가격 버전을 명시한다. 기본 예제는 활성화 허가나 권장 예산이 아니다.
키·인증 파일·프로모션 코드 원문은 Git/문서/로그/브라우저/빌드에 남기지 않는다. 실제 호출을 하지 않았다면 모의 검증과 구분한다.

## 로컬 web·ngrok와 협업

브라우저 → ngrok → 로컬 web → VOC → Agent 흐름과 commerce 연결을 유지한다. 로컬 Agent만 OAuth를 사용한다.
공개 범용 모델 프록시를 만들지 않는다. 화면/API 접근 제어와 고정 중계 경로를 적용하며 DB/Agent/관리 API를 직접 공개하지 않는다.
ngrok 설정 경로와 공개 웹 허용 계정은 별도 로컬 YAML로 관리하고 사용자가 추후 추가한다.
로컬 모델·ngrok 설정을 배포 secret과 섞지 않는다. [ngrok 실행 절차](../ngrok-local-demo.md)를 따른다.

VOC 담당자는 기존 오류 DTO를 유지해 설정·인증/사용량·일시 오류·정보 부족을 구분한다. 같은 키 조회/재전송은 모델을 다시 호출하지 않는다.
실제 모델 품질·일곱 VOC 통합·공개 화면 검증 없이 DONE을 쓰지 않는다. 새로운 모델 연결 구현 완료는 팀 전체 완료와 다르다.
